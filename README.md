# Crystal Frost Experimental

Crystal Frost is an open-source, Unity-based client for Second Life and OpenSim grids. It is built using the Unity 2021.3.6f1 LTS release and the LibreMetaverse library.

## Project Status

This project is currently in an experimental stage. While many features are implemented, there may be bugs and incomplete functionality.

## Getting Started

### Prerequisites

*   **Unity Hub**
*   **Unity 2021.3.6f1 LTS**
*   **Git** (or a Git-compatible client)

### Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/crystal-frost.git
    ```
2.  **Open the project in Unity Hub:**
    *   Launch Unity Hub.
    *   Click the "Add" button.
    *   Navigate to the cloned repository's directory and select it.
3.  **Open the project in Unity:**
    *   Select the project from the list in Unity Hub.
    *   This will launch the Unity editor and load the project.

## Project Structure

The project is organized into several key directories:

*   `Assets/CFEngine`: This directory contains the core engine logic for Crystal Frost.
*   `Assets/ECS`: This directory contains the Entity Component System implementation.
*   `Assets/Editor`: This directory contains custom editor scripts.
*   `Assets/Joystick Pack`: This directory contains the joystick assets and scripts.
*   `Assets/Scripts`: This directory contains various other scripts used in the project.
